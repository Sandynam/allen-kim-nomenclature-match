# I created this to match brain region acronyms or names between Allen and Kim atlases.

### Data from BrainGlobe Atlas API.

- Allen Adult Mouse Brain Atlas - allen_mouse_10um_v1.2 (Wang et al., 2020)
- Enhanced and Unified Mouse Brain Atlas - kim_mouse_10um_v1.1 (Chon et al., 2019)

Example:

| Region Name                   | allen_mouse_10um_v1.2 | kim_mouse_10um_v1.1 |
| ----------------------------- | --------------------- | ------------------- |
| Midbrain raphe nuclei         | RAmb                  | MBRN                |
| Interposed cerebellar nucleus | IP                    | Int                 |
